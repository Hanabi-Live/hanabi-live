# New UI

We are currently testing out an experimental new UI. It can be enabled in the
settings via the "New UI" checkbox in the settings.

## Things Deliberately Not Ported

- The full action log - The value provided by this UI element is minimal and it
  takes a huge amount of real estate.
- Keldon mode - The main value of this mode was clue clarity, which is not as
  much of an issue anymore with the new clue rail.
- "Make numbers match the art style" - This option will be deleted eventually,
  defaulting to always being on.
- Detrimental characters - This feature will be deleted soon.
